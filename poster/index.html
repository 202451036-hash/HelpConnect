HELPCONNECT: EMERGENCY DISASTER RESPONSE & RELIEF PLATFORM

A Real-Time Humanitarian Emergency Triage and Relief Coordination Platform with Resilient Offline SMS Beacon Integration

INTRODUCTION

HelpConnect is a mission-critical emergency assistance platform designed to bridge the gap between stranded survivors, volunteer first responders, and coordinating disaster management authorities during crises. Integrates live geolocation locking, emergency dispatch radar, multi-hazard alerts, and an offline-resilient micro-distress beacon protocol to guarantee communications when cellular internet collapses.

TECH STACK
  • Frontend: React 19, Vite, Lucide Icons, Vanilla CSS Emergency Design System
  • Backend: Node.js, Express.js 5.0 (RESTful API Architecture)
  • Database: MongoDB, Mongoose 8.0 (with embedded In-Memory Mongo fallback)
  • Authentication: JWT (JSON Web Tokens) with bcryptjs salt hashing & role-based RBAC
  • Geospatial Engine: HTML5 Geolocation API, Haversine Distance Formula
  • Offline Protocol: GSM Cellular URI Bridge, Micro-Distress SMS Parser & Telemetry
HOW IT WORKS
  • Distress Initiation: Victims trigger 1-tap SOS or submit prioritized requests (Food, Water, Medical, Rescue) with GPS coordinates.
  • Geospatial Radar: Calculates real-time Haversine distances to nearest active volunteers within an interactive 1–100 km radius slider.
  • Admin Command Center: Authority dispatchers monitor real-time triage telemetry, verify requests, and assign field responders.
  • Mission Execution: Enforces lifecycle progression: Submitted → Assigned → In Progress → Resolved.
  • Public Warning Broadcasts: Rapid emergency alerts (Flood, Quake, Fire, Cyclone) issued directly to affected zones.
FUTURE WORK
  • AI-Driven Priority Scoring: NLP triage engine to objectively rank distress requests by urgency & extract medical vulnerability factors.
  • Mesh Network Relay: Bluetooth Low Energy (BLE) and LoRa peer-to-peer ad-hoc hops between civilian devices when towers fall.
  • Dynamic Hazard Corridors: Evacuation route generation calculating safe paths that avoid active flood and fire hazard polygons.
KEY FEATURES
  • Role-Based Portals: Specialized dashboards for Affected Survivors, Volunteer First Responders, and Admin Dispatchers.
  • Multi-Hazard SOS Beacons: Instant one-touch distress triggers for Water / Floods, Earthquakes / Collapse, and Fire Disasters.
  • Nearby Emergency Radar: Live geospatial radius scanner matching stranded survivors with closest community rescuers.
  • System Telemetry Analytics: Central operations dashboard monitoring triage pipelines, resource breakdown, and active alerts.
  • Direct First Responder Call: One-tap phone dialer bridging volunteers directly to trapped survivors.
NOVELTY: OFFLINE SMS SOS SYSTEM
  • Automatic Connectivity Fallback: Real-time network monitor detects internet/data outages and triggers offline failsafe mode.
  • Hardware-Locked GPS Coordinates: Reads satellite GPS directly via device sensors even with mobile data completely disabled.
  • Compact Micro-Distress Code: Encodes telemetry into 160-char GSM code: HC#SOS#WATER#23.21,72.63#Rahul#Phone for 2G networks.
  • Native 1-Tap SMS Intent: Automatically pre-fills native device SMS app to emergency hotlines (112 / 1078 / 108).
  • Control Room Telemetry Ingest: Inbound SMS decoder transforms raw cellular SMS strings into active Critical SOS rescue tickets.
CONCLUSION

HelpConnect delivers a resilient, unified disaster coordination infrastructure that eliminates critical emergency response delays, optimizes volunteer resource allocation, and ensures life-safety signaling even during severe telecom blackouts.
